# 공개 패키지와 사용자 데이터 경계

공개 소스에는 가상 예시와 범용 규칙만 둔다. 실명·연락처·계정·API 키·개인 경로·고객 원본·실데이터를 넣지 않는다. 스킬을 사용하는 사람의 브랜드·이름·기본 저장 경로를 추정하여 설정하지 않는다.

사용자 입력, 추출 결과, 제작안, 생성 문서, 체크포인트, 개인 별칭, 원본 템플릿은 사용자가 지정한 비공개 작업 위치에 둔다. 프로젝트 내부라면 `inputs/`, `work/`, `outputs/`, `personal-templates/`, `settings/`의 추적 제외 규칙을 확인한다. 공개 스킬의 assets 폴더에 고객 파일을 그대로 복사하지 않는다.

템플릿 등록은 디자인 토큰과 원본 보관을 구분한다. 공개 등록 전에 본문·노트·댓글·숨김 내용·마스터·대체 텍스트·메타데이터·링크·내장 데이터·이미지·QR을 검사하고 재배포 권한을 확인한다. 전체 목록은 PPT 템플릿 안내를 따른다. 검사 불가 대상이 있으면 원본을 공개 자산에서 제외한다.

실제 검사만 `passed`로 기록한다. 키 이름을 제한하거나 작성자 속성만 지우는 것은 개인정보 검사 완료가 아니다. PNG·PDF 미리보기에도 같은 검토를 적용한다. 가상 내용으로 다시 만든 예시를 우선한다.

원본 파일을 받았다는 사실은 공개 허락이 아니다. 스킬은 외부 게시·메시지 전송을 자동 수행하지 않는다. 오류 로그와 체크포인트도 고객 데이터이므로 공개 배포물에 포함하지 않는다. 생성 문서의 기본 작성자는 범용 값 `Office Maker`다.
