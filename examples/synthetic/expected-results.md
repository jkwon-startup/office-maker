# 가상 예시의 기대 결과

`input.json`은 가상 업무 개선 워크숍이며 실제 조직·고객·성과가 없다. sources는 비어 있고 수치 실적도 없다.

- dry-run: PLANNED, ppt/excel/word 제작안, 파일 생성 없음.
- PPT: 표지 + 핵심 내용 3장 + 마무리 = 5장, 5개의 발표자 노트. 기본 중립 디자인과 편집 가능한 텍스트.
- 엑셀: 핵심 내용 3행을 가진 Action plan 시트, Item/Owner/Status 열. 담당자·상태는 빈 값.
- 워드: 제목, Overview, Key points, Next action 절. 편집 가능한 문단.
- 모든 의존성이 있으면 최종 상태 COMPLETE. 각 파일의 화면 검토 미실행은 WARN으로 남는다.
- 의존성 누락 또는 출력 충돌이면 해당 형식 FAILED, 다른 형식은 계속 수행한다.
- 동일 입력·폴더로 재개하면 해시가 일치하는 성공 파일을 다시 쓰지 않는다.

자동 생성 후 실제 내용·줄바꿈·폰트·페이지 및 앱 호환성 검토가 별도로 필요하다.
