# 가상 예제와 미리보기 검토

`input.json`은 가상 업무 개선 워크숍입니다. 실제 조직·고객·담당자·성과가 없으며 외부 출처를 가장하지 않습니다. 30분·20분·10분·약 33.3%는 계산 연습용 가정입니다.

| 형식 | 제작 결과 | 선택한 기본 프로필 |
| --- | --- | --- |
| PPT | 비교·로드맵·KPI를 포함한 5장, 발표자 노트 5개 | 기본 발표 T001 v1.0.0 |
| 엑셀 | 실행 계획 3행, 가상 계산 1행의 2시트 | 기본 실행표 E001 v1.0.0 |
| 워드 | 요약·문제와 개선 방향·실행 계획·검토 기준·다음 행동의 5절, 실행 계획표 | 기본 보고서 W001 v1.0.0 |

미리보기는 이 입력으로 실제 생성한 파일을 LibreOffice에서 PDF로 렌더링한 결과입니다.

## 확인한 범위

2026-10-03, macOS와 LibreOffice 26.8에서 기본 디자인과 위 이름으로 선택한 프로필을 적용한 실제 결과를 확인했습니다.

- PPT: 5장과 노트 5개, 편집 가능한 텍스트·도형. 전체 렌더링의 한글·비교 열·로드맵·KPI·페이지 경계를 확인했습니다. 표지 부제 중복을 수정했고 한국어 지표에는 “가정”을 표시합니다.
- 엑셀: 2시트의 표와 소요 시간 단위. D2의 `B2-C2`와 E2의 `D2/B2`에 각각 10과 10/30의 검증된 캐시를 넣었습니다. LibreOffice 렌더링에서 10과 33.3% 표시를 확인했습니다. ExcelJS가 수식을 계산한다는 뜻은 아닙니다.
- 워드: 실제 제목 스타일·5절 순서·표 머리글·본문을 확인했습니다. 이 환경에서는 A4 세로 1페이지로 렌더링되었습니다. 다른 앱·글꼴에서도 1페이지임을 보장하지 않습니다.
- 개인정보·자산: 가상 입력, 중립 프로필과 Office Maker 생성 메타데이터만 사용했습니다. 고객 자료·개인 브랜드·글꼴 파일은 포함하지 않았습니다. PNG는 PDF 페이지의 픽셀을 다시 저장했고 텍스트·EXIF 메타데이터를 포함하지 않습니다. 엑셀 이미지는 실제 첫 시트의 표 영역을 발췌했습니다.

프로필의 `checks: passed`는 위 가상 예제와 LibreOffice 확인 범위를 뜻합니다. Microsoft PowerPoint·Excel·Word, 실제 ChatGPT 대화형 실행은 별도 검증 대상입니다. 임의의 새 문서에 대한 화면 검토 완료를 의미하지 않습니다.

## 파이프라인 동작

- dry-run: PLANNED, 세 형식의 제작안. 파일 생성 없음.
- 정상 생성: COMPLETE, 파일 세 개. 생성기가 직접 화면을 검사하지 않으므로 결과의 WARN은 유지합니다.
- 한 형식 실패: 실패 원인을 기록하며 나머지 형식은 계속 실행합니다.
- 동일 입력·폴더로 재개: 해시가 일치하는 성공 파일을 다시 쓰지 않습니다.
- 입력 변경: 새 결과 폴더와 체크포인트가 필요합니다.
