# Office Maker 0.1.1

설치 후 첫 결과를 확인하는 흐름을 간단하게 만든 초기 공개 버전입니다. 기존 v0.1.0 태그와 릴리스를 유지합니다.

## 변경사항

- README에 사용 대상과 실제 가상 예제 미리보기 세 개를 추가했습니다.
- 설치 경로를 플러그인 설치 두 줄로 통일하고 quickstart를 설치→예제 요청→결과 확인으로 정리했습니다.
- 유지보수용 설치·테스트·배포 검사는 별도 개발자 문서로 옮겼습니다.
- 네 스킬에 공통 첫 실행 준비 절차를 연결했습니다. 실행 위치와 의존성을 확인하고, 허용된 환경에서 설치하거나 읽기 전용 본체의 비공개 실행 복사본을 준비합니다.
- 형식별 중립 프로필 T001·E001·W001을 제공하고 가상 예제를 비교·로드맵·계산표·보고서로 보강했습니다.
- PPT 표지의 부제 중복을 수정하고 한국어 지표에 읽기 쉬운 상태 표시를 적용했습니다.
- 공개 미리보기 PNG 세 개만 허용하고 숨은 메타데이터를 차단하는 배포 검사를 추가했습니다.
- GitHub Issues로 피드백을 받을 수 있도록 안내했습니다.

## 검증과 한계

48개 자동 테스트로 실제 파일 생성·템플릿 선택·재개·실패 처리·첫 실행 준비·배포 경계를 검사합니다. 공개 가상 결과는 LibreOffice에서 렌더링했습니다. 자세한 범위는 [예제 검토 기록](../examples/synthetic/expected-results.md)에 있습니다.

첫 실행 준비는 Node.js 20 이상·npm과 호스트의 실행·네트워크·쓰기 권한이 필요합니다. 모든 환경에서 무조건 자동 설치되는 기능으로 보장하지 않습니다. 준비 실패를 생성 성공으로 표시하지 않습니다.

Microsoft Office와 실제 ChatGPT 대화형 동작은 별도 검증 대상입니다. 원본 Office 구조 재사용, 사진·차트 삽입, 자동 화면 검사는 현재 지원하지 않습니다. ExcelJS는 수식을 계산하지 않습니다. 가상 예제 외의 파일은 실제 내용·화면·글꼴과 앱 호환성을 별도로 확인해야 합니다.

배포 ZIP은 공개 패키지 허용 목록의 파일만 포함합니다. 고객 원문·개인 템플릿·별칭·환경 파일·로컬 결과는 포함하지 않습니다.
