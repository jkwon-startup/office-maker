# Office Maker 0.1.0

초기 공개 버전입니다. Codex에서 편집 가능한 PPTX·XLSX·DOCX를 만들고, 하나의 자료를 세 형식으로 확장하는 OSMU 파이프라인을 제공합니다.

## 제공 기능

- PPT 만들기, 엑셀 만들기, 보고서 만들기, 한 번에 만들기 스킬.
- 누락된 중요한 입력 질문과 답 대기, 공통 입력 재사용.
- 개인 라이브러리의 템플릿 이름·고정 번호·버전 선택, 검토 전 템플릿 차단.
- 워드 양식의 필수 절·순서·제목·표 머리글 대응.
- 사용자 별칭 생성 도구, 기존 출력 덮어쓰기 방지.
- 형식별 실패 기록과 체크포인트 재개, 성공 결과 해시 확인.
- 고객 설치 안내, 합성 예제, 배포 파일 검사와 운영체제별 CI.

## 검증 범위

로컬에서 38개 자동 검사가 모두 통과했습니다. 검사에는 실제 세 파일 생성·다시 읽기·재개, 템플릿 적용, 별칭·출력 보호가 포함됩니다. LibreOffice에서 가상 예제의 한글·화면, 긴 워드 표의 페이지 나눔·머리글 반복, 엑셀 수식 재계산을 확인했습니다. Codex 목록 API에서 스킬과 검사용 별칭을 발견했습니다.

실제 플러그인 캐시 설치 후 전체 대화형 작업, 일반 ChatGPT에서의 파일 실행·다운로드, Microsoft Office 호환성은 별도 검증 대상입니다. GitHub CI 결과는 저장소의 Actions에서 확인합니다. Linux·macOS·Windows 검사 구성이 모든 고객 환경의 호환성을 보장하지는 않습니다.

## 지원 한계

CLI는 AI를 호출하지 않고 JSON 제작안을 렌더링합니다. 기본 OSMU 계획은 단순 시작안이며 목적별 상세 제작안은 AI가 작성합니다. 원본 Office 파일의 마스터·로고·복잡한 구조를 그대로 재사용하거나 템플릿을 자동 추출·등록하는 기능은 없습니다. 디자인 프로필을 적용한 새 파일을 생성합니다. ExcelJS는 수식을 계산하지 않습니다.

공개 템플릿 목록은 비어 있으며 실제 고객 자료·개인 양식·개인 별칭·글꼴 파일은 포함하지 않습니다. Node.js 20 이상과 실행 권한이 있는 호스트가 필요합니다. 외부 Google 서비스와 별도 유료 API는 필수 의존성이 아닙니다.

## 의존성 패치

PPTXGenJS의 image-size를 2.0.3, ExcelJS의 uuid를 11.1.1로 고정하는 scoped override를 적용했습니다. 전체 회귀검사와 CommonJS uuid 호출·PNG 크기 해석 검사가 통과했고, 공개 전 npm audit에서 알려진 취약점 0건을 확인했습니다. [image-size 권고](https://github.com/advisories/GHSA-5p2g-fcmc-qvqq), [uuid 권고](https://github.com/advisories/GHSA-w5hq-g745-h8pq).

문제 제보는 GitHub Issues에 버전·환경·오류 코드와 가상 재현 입력을 제공합니다. 실제 고객 데이터·개인 경로·비밀키는 제외합니다.
