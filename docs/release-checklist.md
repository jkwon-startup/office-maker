# 배포 점검표

로컬 준비와 실제 고객 환경 검증을 구분합니다. GitHub에 올렸다는 사실만으로 ChatGPT 설치나 모든 운영체제의 호환성이 보장되지 않습니다. 공개 전 아래 항목을 확인하고 검토 근거를 개인 작업 폴더에 기록합니다.

| 단계 | 완료 기준 |
| --- | --- |
| 1. 독립 저장소 | Git 루트가 이 프로젝트이며 고객 자료·개인 AGENTS·환경 파일·결과물·로그가 추적되지 않음 |
| 2. 새 설치 | 배포 허용 파일만 복사한 새 폴더에서 npm ci, doctor, 테스트와 실제 세 파일 생성 성공 |
| 3. 실제 결과 | 한글·글꼴 대체·줄바꿈·페이지·긴 표 검토, 수식 앱 재계산과 기대값 대조; 사용한 앱과 미실행 앱 명시 |
| 4. 사용자 흐름 | 필요한 입력 질문·답 대기·이미 준 값 재사용, 템플릿 ID/이름/버전 선택, 모호함·draft 차단, 별칭 발견 검증 |
| 5. 공개 범위 | release:check 통과, 추적 파일과 배포 목록 일치, 개인정보·메타데이터·자산 권리 수동 검토 |
| 6. 자동 검사 | CI에서 깨끗한 설치·의존성 취약점 검사·테스트·실제 OSMU 실행, 대상 운영체제의 GitHub 실행 결과 확인 |
| 7. 고객 안내 | 실제 설치 방식·호출·템플릿 등록·별칭·예제·제약·문의 방식 검토; 버전과 라이선스 확인 |

## 반복 검사

```sh
npm ci --ignore-scripts
npm run doctor
npm test
npm run release:check
npm audit --omit=dev --audit-level=moderate
npm run osmu -- --input examples/synthetic/input.json --output outputs/release-demo --run-dir work/release-demo
```

`release:check`는 허용 파일 목록, 개인 경로·연락처·비밀키 표식, JSON 문법, 필수 패키지 파일과 Git 추적 범위를 검사합니다. npm의 공개 공급자 경고문에 포함된 연락처는 연락처 검사에서 제외하지만 경로·비밀키 검사는 유지합니다. 이 검사는 모든 개인정보·권리·내용 품질을 자동 판정하지 않습니다. 추가 바이너리 자산은 별도 검토 없이 배포 대상으로 통과시키지 않습니다.

`doctor` 통과와 생성기 `WARN`은 함께 나올 수 있습니다. 화면 검사와 앱 재계산 상태는 별도 근거로 기록하며 생성기의 미실행 경고를 임의 삭제하지 않습니다. 기본 OSMU 계획은 단순 시작안이므로 AI가 목적별 상세 계획을 작성해야 합니다.

## 실제 호스트에서 확인할 시나리오

1. 사용자에게 목적만 받은 상태에서 자료·독자·템플릿·저장 위치를 묻고 답을 기다리는지 확인한다.
2. 이미 준 입력을 다시 묻지 않고, 추천값 사용은 명시적으로 허용받는지 확인한다.
3. 여러 개인 템플릿의 이름·고정 번호·지정 버전이 동일한 프로필을 선택하는지 확인한다.
4. 모호한 이름·필수 절 누락·미등록 항목·draft 템플릿을 거절하는지 확인한다.
5. 사용자 별칭을 실제 발견 위치에 만들고 호출해 본체와 동일한 흐름으로 이어지는지 확인한다.
6. 설치된 **캐시 복사본**에서 의존성이 사용 가능하고 세 형식이 생성되는지 확인한다.
7. 지원하려는 ChatGPT 세션에서 파일 실행과 다운로드가 가능한지 별도로 확인한다.

단위 테스트의 가상 템플릿·별칭 검사나 읽기 전용 스킬 목록 API는 전체 대화형 실행의 통과 근거가 아닙니다. 각 시나리오의 실제 수행 여부를 구분해 기록합니다.

## 공개 직전

공개 원격 주소·소유자·저장소 이름과 공개 여부를 사용자가 확정합니다. 커밋 작성자와 이메일은 공개 기록에 남으므로 사용자가 선택한 공개용 정보로 설정합니다. `git add .`에 의존하지 않고 검토한 배포 목록만 포함합니다. ZIP·압축본에도 고객 데이터·로컬 설정·검사 캐시를 넣지 않습니다. 실패한 의존성 검사나 미수행 호스트 검증은 완료로 표시하지 않습니다.

최초 버전은 검증된 범위와 미검증 범위를 명시한 배포 후보로 검토합니다. 고객에게 전달할 완성판 표시는 필요한 호스트·Office 앱·운영체제 검증을 마친 뒤 결정합니다.
